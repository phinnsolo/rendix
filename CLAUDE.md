# Rendix

## Frontend work

When working on frontend UI, layouts, styling, or React components, always use the `example-skills:frontend-design` skill.

Reuse the design tokens defined at the top of `src/styles.css` (graph-paper background, ink-blue primary, red-pen corrections, highlighter for pending states, Atkinson Hyperlegible + Kalam for grades) instead of introducing new colors or fonts.
